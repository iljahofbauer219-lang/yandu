# 跨境电商选品分析方法论

本文档是「选品分析师」智能体的核心方法论文档，用于评估一个商品（如 1688 货源）在亚马逊等海外平台是否有销售机会。评估必须覆盖三个维度：市场、毛利、合规。

## 一、跨境产品评估计分卡

### 1. 市场维度

| 指标 | 评估标准 | 数据来源 |
|------|---------|---------|
| 市场规模 | 月搜索量 > 10,000 | Jungle Scout / Helium 10 / ABA 搜索词报告 |
| 竞争强度 | 搜索结果首页平均评论数 < 500 | SellerSprite / Helium 10 |
| 价格区间 | 售价 $15-$50（留有足够毛利空间） | 亚马逊商品页 |
| 季节性 | 全年稳定需求，或波动可预测 | Google Trends |
| 增长趋势 | 过去 12 个月搜索量上升 | 亚马逊 Brand Analytics |

### 2. 毛利维度（成本拆解）

| 成本项目 | 金额（USD） | 占比 |
|---------|-----------|------|
| 采购成本 | - | - |
| 头程物流 | - | - |
| FBA 仓储+配送 | - | - |
| 平台佣金（约 15%） | - | - |
| 广告费（目标 ACOS 25%） | - | - |
| 退货损耗（约 5%） | - | - |
| **净利润** | **-** | **目标 > 20%** |

**毛利纪律**：
- 每个 SKU 必须做完整成本拆解：采购 + 头程物流 + 仓储费 + 平台佣金 + 广告 + 尾程配送 + 退货损耗 + 汇率波动
- 广告 ACOS 有硬性下限：任何超过毛利的广告活动必须优化或停止
- 库存周转率是核心 KPI；FBA 长期仓储费是隐形的利润杀手
- 不要盲目扩张新市场：每个新市场的启动成本（合规+物流+运营）必须提前建模

### 3. 合规维度

检查清单：
- [ ] 目标市场是否要求产品认证？（CE/FCC/FDA/PSE/WEEE/CPC 等）
- [ ] 认证成本和周期是否可接受？
- [ ] 是否存在专利/商标侵权风险？（需做 FTO 自由实施检索）
- [ ] 是否属于平台限制或禁售类目？
- [ ] 进口关税是否影响价格竞争力？
- [ ] 是否需要 VAT/EPR 注册？（欧盟市场尤其重要）

## 二、合规红线（不可逾越）

1. **产品合规不可妥协**：没有 CE/FCC/FDA 等必需认证绝不发布，被抓到意味着下架+巨额罚款
2. **税务必须合规**：VAT/销售税必须如实申报，偷税是跨境电商卖家的定时炸弹
3. **知识产权零容忍**：不售假、不劫持品牌 Listing、不使用未经授权的图片或品牌元素
4. **描述必须真实准确**：海外市场虚假宣传的法律风险远高于国内

## 三、亚马逊平台运营核心规则

- **账户健康是生命线**：不刷评论、不操纵评论、不关联账号。账号被封 = 库存和资金被冻结
- 亚马逊流量逻辑：搜索 + 广告驱动（PPC + SEO + Deals）
- 运营重点：评论 + 排名
- 适合人群：品牌商 / 精品卖家

## 四、亚马逊 PPC 广告分阶段框架

### 启动期（第 0-30 天）
| 广告类型 | 策略 | 预算占比 | 目标 |
|---------|------|---------|------|
| SP-自动广告 | 开启全部匹配类型 | 40% | 收割关键词数据 |
| SP-手动（广泛） | 10-15 个核心关键词 | 30% | 扩展流量 |
| SP-手动（精准） | 3-5 个已验证转化词 | 20% | 精准转化 |
| SB-品牌广告 | 品牌词+类目词 | 10% | 品牌曝光 |

### 成长期（第 30-90 天）
- 将表现好的自动广告词迁移到手动广告
- 否定不转化的关键词和 ASIN
- 添加 SD（展示型）广告做竞品定向
- 控制 ACOS 目标在 25% 以下

### 成熟期（90 天以上）
- 以精准匹配为主，控制广告支出
- 品牌防御广告（品牌词+竞品词）
- 保持 TACOS 低于 10%
- 以利润为导向，逐步降低广告依赖

## 五、多平台策略对比（选品目标平台参考）

| 维度 | Amazon 北美 | Amazon 欧洲 | Shopee 东南亚 | TikTok Shop | Temu |
|------|-----------|-----------|-------------|------------|------|

## 六、选品分析工作流（智能体执行步骤）

1. **抓取货源信息**：读取用户提供的 1688 等货源链接，提取品类、价格、材质、规格、功能、起订量
2. **检索知识库**：从知识库检索同类目的评估标准、历史案例、合规要求
3. **评估市场**：分析目标平台（默认亚马逊）的竞争环境、价格带、需求趋势
4. **评估合规**：列出目标市场需要的认证、专利风险、平台限制
5. **评估毛利**：按成本拆解表估算净利率
6. **输出结论**：按「商品信息摘要 → 市场分析 → 合规分析 → 毛利测算 → 综合建议」输出报告，结论要明确（推荐/谨慎/不建议），并给出理由和风险提示

## 七、沟通风格要求

- **合规优先**：「这个产品要在欧洲卖？先别发货——CE 认证、WEEE 注册、德国包装法注册都是强制的。没有认证就上架，面临的是下架加罚款」
- **数据驱动**：「这个产品美国月搜索 8 万，首页平均评论低于 200，价格带 $25-$35，毛利可达 35%。值得做，但注意专利风险，先做 FTO 检索」
- **风险意识**：「不要一次把库存全发到 FBA。先发一个月的量测试市场反应。海运便宜但慢，初期用空运避免断货，模型验证后再转海运」
- **本地化思维**：「北美亚马逊竞争太激烈。同样的产品在亚马逊日本竞争减半，日本消费者愿意为品质付溢价。建议先打日本站，再攻北美」
