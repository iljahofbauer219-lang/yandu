### 表结构与字段定义

#### 核心新表结构

**inbound_processing_items（入库处理队列表）** - 已重构
- id: TEXT PRIMARY KEY - 唯一标识符
- origin: TEXT NOT NULL - 来源类型（SELECTION/ERP）
- source_id: TEXT NOT NULL - 源ID（选品ID或ERP商品ID）
- selection_id: TEXT NOT NULL DEFAULT '' - 选品记录ID
- status: TEXT NOT NULL DEFAULT 'PENDING' - 状态（PENDING/CONFIRMED/REJECTED）
- snapshot_json: TEXT NOT NULL DEFAULT '{}' - JSON格式的快照数据
- created_at: TEXT NOT NULL - 创建时间
- updated_at: TEXT NOT NULL - 更新时间
- confirmed_at: TEXT - 确认时间

**pallet_warehouse_items（货盘仓库物品表）** - 新增
- id: TEXT PRIMARY KEY - 唯一标识符
- warehouse_product_id: TEXT NOT NULL UNIQUE - 关联正式入库商品ID
- warehouse_code: TEXT NOT NULL - 仓库代码
- item_code: TEXT NOT NULL DEFAULT '' - 商品编码
- title: TEXT NOT NULL - 商品标题
- image_url: TEXT NOT NULL DEFAULT '' - 图片URL
- price_text: TEXT NOT NULL DEFAULT '' - 价格文本
- category: TEXT NOT NULL DEFAULT '未分类' - 一级类目
- subcategory: TEXT NOT NULL DEFAULT '待人工分类' - 二级类目
- tertiary_category: TEXT NOT NULL DEFAULT '待细分' - 三级类目
- source_url: TEXT NOT NULL DEFAULT '' - 来源URL
- stored_at: TEXT NOT NULL - 存储时间

#### 现有业务表结构
- **supply_warehouse_products**：正式入库商品管理
- **selection_records**：选品记录管理
- **marketplace_selection_products**：平台选品管理
- **compliance_* 系列表**：合规相关表
- **ebay_* 系列表**：eBay 相关表

### 索引策略与查询优化

#### 关键索引
- **uq_inbound_origin_source**: `(origin, source_id)` 唯一索引 - 防止重复入库
- **idx_pallet_warehouse_code**: `(warehouse_code, stored_at DESC)` - 优化货盘查询
- **idx_supply_warehouse_code**: `(warehouse_code, status, updated_at DESC)` - 优化供应仓查询

#### 查询优化策略
- **JSON快照解析**：使用 SQLite 的 JSON 函数优化快照数据访问
- **批量操作**：使用事务批量处理入库确认和退回操作
- **状态过滤**：利用状态字段进行高效的队列筛选
- **时间排序**：按更新时间倒序排列，支持最新的入库项优先显示

## 性能考虑
- **连接池化**：SQLite 单连接模式，避免频繁建立连接
- **查询优化**：合理使用索引，避免 N+1 查询问题
- **批量操作**：使用事务批量处理减少数据库往返
- **缓存策略**：对不常变化的配置可考虑应用层缓存
- **监控指标**：记录慢查询和数据库操作统计

## 故障排查指南
- **连接失败**：检查 SQLite 文件权限和磁盘空间
- **迁移失败**：查看迁移日志，确认数据库版本和结构一致性
- **数据不一致**：验证外键约束和事务完整性
- **性能问题**：使用 EXPLAIN 分析慢查询，检查索引使用情况

### SQL查询示例

#### 入库处理查询
```sql
-- 查询待确认的入库队列
SELECT * FROM inbound_processing_items 
WHERE status = 'PENDING' 
ORDER BY updated_at DESC;

-- 查询特定来源的入库记录
SELECT * FROM inbound_processing_items 
WHERE origin = 'SELECTION' AND source_id = 'sel-1';

-- 查询已确认的入库记录
SELECT * FROM inbound_processing_items 
WHERE status = 'CONFIRMED' 
ORDER BY confirmed_at DESC;
```

#### 货盘管理查询
```sql
-- 查询货盘仓库物品
SELECT * FROM pallet_warehouse_items

ORDER BY stored_at DESC;

SELECT * FROM pallet_warehouse_items 
WHERE warehouse_product_id = 'wh-product-id';
```
