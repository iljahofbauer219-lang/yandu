## 简介
本仓库的后端服务基于 Fastify 构建，提供认证、权限、组织隔离、业务模块路由（如 eBay、合规、媒体、AI 等）以及统一的错误处理。数据层使用 Prisma 连接 PostgreSQL，并通过环境变量集中管理配置。Electron 主进程通过 serverConfig 决定本地或远程模式，从而决定是否拉起本地服务栈。

**新增功能**：Linduo 模型定价系统，支持 OpenAI、Google、Anthropic、Vidu 等厂商的模型价格爬取、比较和展示，包含自动登录、定时刷新、价格持久化等功能。**重大升级**：RBAC 权限系统升级为两级菜单权限体系，支持侧边栏菜单与栏目内入口的精细化权限控制；IPC 通信增强错误处理和用户友好的中文错误提示。

## 架构总览
后端以 Fastify 为 HTTP 框架，通过插件机制扩展能力；所有请求先经过全局错误处理与鉴权插件，再进入具体业务路由；数据访问统一通过 Prisma 客户端进行。Electron 主进程根据 serverConfig 判断是否启动本地服务栈，实现"本地开发/测试"与"远程生产"两种运行模式。

**新增 Linduo 定价架构**：通过 Playwright 自动化浏览器抓取 api000.com 价格页面，使用加密存储的凭据自动登录，定时任务每日刷新价格数据，前端提供模型广场界面进行价格比较。

**新增 RBAC 权限架构**：采用前后端分离的两级权限设计，前端定义权限树，服务端生成白名单，支持侧边栏菜单与栏目内入口的精细化权限控制。

**新增 IPC 通信架构**：桌面端错误处理增强，支持通道未注册、会话过期、超时等场景的用户友好提示，并提供会话自动重试机制。

### RBAC 两级菜单权限体系（重大升级）

#### 权限树定义（menuPermissionTree.ts）
- 两级权限结构：一级=侧边栏菜单（group='sidebar'），二级=栏目内实际渲染的入口卡片（group='entry'）。
- 支持11个一级栏目和148个权限码，其中货盘采集二级权限达114个。
- 提供权限状态计算、菜单访问判断、权限展开等核心工具函数。
- 前端与管理界面只暴露一级勾选框，二级权限由 expandMenuSelection 自动补齐。

#### 服务端权限白名单（menuPermissions.generated.ts）
- 由 tools/gen-server-menu-permissions.ts 从前端的 MENU_PERMISSION_TREE 自动生成。
- 作为成员权限保存的唯一白名单，不在其中的权限码会被静默丢弃。
- 包含完整的权限码列表和对应的中文标签映射。

#### 权限配置（permissions.ts）
- 合并操作类权限和菜单类权限，形成完整的 PERMISSIONS 数组。
- 定义预置角色权限：OWNER（主帐号）、OPERATOR（运营）、COLLECTOR（采集专员）、PUBLISHER（发布员）、VIEWER（只读）。
- 每个预置角色都有明确的权限边界和业务职责。

#### 权限迁移脚本（migrate-menu-permissions.ts）
- 幂等可重跑的迁移脚本，支持旧模块码到新两级码的映射转换。
- 自动同步现存组织系统预置角色的权限为新默认值。
- 支持 module.ebay、module.ai_crossborder、module.compliance、module.legacy、module.admin 等旧权限码的迁移。

#### 价格爬取器（pricing-scraper.ts）
- 使用 Playwright Core 启动 headless Chrome 浏览器
- 自动登录 api000.com 并维护 Cookie 会话
- 智能解析价格卡片，支持多种选择器策略
- 识别不同供应商（OpenAI、Google、Anthropic、Vidu）
- 失败时回退到预设价格数据，标记 stale=true

#### 登录态管理（pricing-login.ts）
- 使用 AES-256-GCM 加密存储用户密码
- 管理 Cookie 会话和过期时间
- 自动检测是否需要重新登录
- 安全地解密密码用于自动重登

## 性能与可扩展性
- 中间件顺序：CORS → JWT → 自定义鉴权 → 业务路由。将错误处理置于路由之前，确保一致的错误响应格式。
- 数据库连接：单例 Prisma 客户端，建议在生产环境启用连接池与慢查询日志。
- 配置外置：所有敏感信息与运行参数通过环境变量注入，便于容器化与多环境管理。
- 可扩展点：新增业务模块只需在 app.ts 中注册路由前缀，并在 modules 下实现 routes.ts；权限控制通过 requirePermission 快速接入。
- **新增**：Linduo 定价系统采用异步调度，避免阻塞主线程；浏览器实例复用减少资源消耗；价格数据缓存提升响应速度。
- **新增**：RBAC 权限系统通过生成式白名单减少运行时权限检查开销；前端权限树提供高效的权限状态计算。
- **新增**：IPC 错误处理采用轻量级字符串匹配，避免额外依赖；会话重试机制减少用户交互成本。

## 故障排查指南
- 启动失败：检查 index.ts 的端口占用与数据库连通性；查看控制台错误日志。
- 认证失败：确认 JWT_SECRET、ACCESS_TOKEN_TTL、REFRESH_TOKEN_TTL_DAYS 配置正确；检查用户状态是否为 ACTIVE。
- 权限不足：确认角色权限已分配，或通过 requirePermission 守卫限制访问。
- 媒体访问：MEDIA_DRIVER=local 时需确保 MEDIA_LOCAL_DIR 可写；OSS 模式下需配置正确的 Bucket/Endpoint/Key。
- 健康检查：GET /health 应返回 ok 与时间戳，用于探针与健康检查。
- **新增**：Linduo 定价问题：
  - 浏览器启动失败：检查 LINDUO_PRICING_CHROME_PATH 配置是否正确
  - 登录失败：确认 LINDUO_PRICING_USERNAME 和 LINDUO_PRICING_PASSWORD 配置正确
  - 价格抓取失败：检查网络连接和 api000.com 网站可用性
  - Cookie 失效：系统会自动重新登录，如失败请检查加密密钥配置
- **新增**：RBAC 权限问题：
  - 权限不生效：检查 menuPermissions.generated.ts 是否与前端权限树同步
  - 迁移失败：运行 pnpm migrate:menu-perms 重新执行权限迁移
  - 权限码漂移：运行权限对账测试验证前后端一致性
- **新增**：IPC 通信问题：
  - 通道未注册：重启应用加载新版本，检查 ipcMain.handle 是否正确注册
  - 会话过期：使用 runWithSessionRetry 自动处理会话刷新
  - 错误提示不明确：检查 desktopErrorText 是否正确处理错误类型

## 结论
该后端服务以 Fastify 为核心，结合 Prisma 与模块化路由，提供了完善的认证、权限、组织隔离与丰富的业务模块。通过环境变量与插件机制，具备良好的可配置性与可扩展性。配合 Electron 主进程的本地/远程模式切换，可满足开发与生产环境的差异化需求。

**重大升级亮点**：
1. **RBAC 两级菜单权限体系**：实现了精细化的权限控制，支持侧边栏菜单与栏目内入口的独立权限管理，提供完整的权限迁移工具和前后端一致性保障。
2. **Linduo 模型定价系统**：实现了跨厂商模型价格的自动化采集、比较和展示，为开发者提供了便捷的模型选型工具，支持 OpenAI、Google、Anthropic、Vidu 等主流厂商的价格对比。
3. **IPC 通信增强**：大幅改善了桌面端用户体验，提供用户友好的中文错误提示和自动会话重试机制，减少了用户操作复杂度。
4. **数据库安全优化**：主动清理潜在的敏感数据泄露面，体现了安全最佳实践。

这些改进显著提升了系统的可维护性、安全性和用户体验，为跨境电商平台的稳定运行提供了坚实的技术基础。
