本项目的配置系统基于 Electron 主进程启动时加载 `.env.local` 文件，将键值对注入 `process.env`，随后各服务模块通过 `process.env.XXX` 读取运行时配置。该方案简单直接，未引入 dotenv 等第三方库，所有配置项均为字符串类型，由调用方自行解析（如逗号分隔的模型列表）。

**加载机制与优先级**
- 应用入口 `src/main/main.ts` 在模块初始化阶段执行 `loadLocalEnvironment()`，按顺序查找 `app.getAppPath()/.env.local` 和 `process.cwd()/.env.local`，找到后逐行解析 `KEY=VALUE` 格式，跳过已存在的 `process.env` 变量，支持单/双引号包裹的值去引号处理。
- 该函数在 `main.ts` 第 120 行被直接调用，早于任何服务实例化，确保后续代码能读到配置。
- 没有 `.env`、`.env.development`、`.env.production` 等多环境文件区分；也没有命令行参数或配置文件覆盖机制。

**配置项分类**
- **eBay OAuth 凭据**：`EBAY_CLIENT_ID`、`EBAY_CLIENT_SECRET`、`EBAY_RUNAME`，用于正式环境授权流程，缺失时 `EbayService.configuration().configured` 返回 false，并阻止生成授权 URL。
- **百炼（Bailian）AI 服务**：`BAILIAN_API_KEY`、`BAILIAN_BASE_URL`、`BAILIAN_VISION_MODEL`、`BAILIAN_IMAGE_GROUNDING_MODEL`，默认 Base URL 为 `https://dashscope.aliuncs.com/compatible-mode/v1`。
- **DeepSeek 翻译优化**：`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`，默认 Base URL 为 `https://api.deepseek.com`。
- **火山方舟视频/TTS**：`ARK_API_KEY`、`ARK_BASE_URL`、`ARK_VIDEO_MODEL`、`ARK_VIDEO_MODELS`（逗号分隔）、`ARK_TEXT_MODELS`；TTS 相关：`VOLC_TTS_APP_ID`、`VOLC_TTS_ACCESS_TOKEN`、`VOLC_TTS_BASE_URL`、`VOLC_TTS_RESOURCE_ID`、`VOLC_TTS_VOICE_*` 系列语音角色名。
- **Vite 构建期变量**：开发脚本中通过 `VITE_DEV_SERVER_URL=http://localhost:5173` 注入，供渲染进程使用。

**安全与存储**
- 敏感凭据（eBay 访问令牌、刷新令牌、用户密码）不持久化到 `.env.local`，而是通过 Electron `safeStorage` 加密后存入 SQLite 数据库，运行时解密使用。
- `.env.example` 提供模板，实际密钥应放入 `.env.local`（已在 `.gitignore` 中忽略），避免泄露。

**Python 工具配置**
- `tools/realshift/realshift/config.py` 使用 Python dataclass 定义图像处理 Profile（light/balanced/strong），通过 `get_profile(name)` 获取，属于硬编码配置而非外部文件加载。
- `worker.py` 通过 argparse 接收命令行参数（--input/--output/--profile/--iterations/--seed），无外部配置文件。

**约定与约束**
- 所有环境变量名必须为大写字母、数字和下划线组合，正则 `^([A-Z0-9_]+)=(.*)$` 匹配，不符合的行会被忽略。
- 逗号分隔的配置（如 `ARK_VIDEO_MODELS`）在服务层通过 `split(',')` 解析并去重过滤空值。
- 缺少关键凭据时，对应服务会抛出明确错误（如 eBay 授权前检查、TTS 凭证为空时页面禁用），而非静默失败。
- 不存在运行时热重载配置的能力，修改 `.env.local` 需重启应用生效。
