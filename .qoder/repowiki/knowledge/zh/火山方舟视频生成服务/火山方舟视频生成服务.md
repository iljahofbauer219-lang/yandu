### 火山方舟 AI 视频生成
- 角色：基于产品图片生成电商宣传视频，支持多种视频模型选择
- 集成点：通过 HTTP API 调用 `https://ark.cn-beijing.volces.com/api/v3`，使用 API Key 认证
- 模型支持：Seedance 2.0（高质量）、Seedance 2.0 Fast（日常推荐）、Seedance 2.0 Mini（经济预览）
- 文本模型：Seed 2.1 Turbo、Seed 2.1 Pro、Seed Evolving，用于文案生成和优化
- 语音合成：豆包 TTS 2.0，支持男女声多种音色，通过独立的 VolcEngine TTS API 调用
- 视频处理：集成 FFmpeg 进行视频剪辑、字幕添加、格式转换等本地处理
- 配置项：`ARK_API_KEY`、`ARK_BASE_URL`、`ARK_VIDEO_MODEL`、`ARK_TEXT_MODELS`
