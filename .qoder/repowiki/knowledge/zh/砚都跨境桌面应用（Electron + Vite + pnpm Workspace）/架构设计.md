根目录作为 monorepo 入口，使用 pnpm-workspace 聚合五个子模块：main_process（Electron 主进程）、renderer_ui（Vite + React 渲染器）、shared_code（跨模块 TypeScript 类型与规则库）、browser_extension（Chrome 采集扩展）与 tools（Python/Node 辅助脚本）。TypeScript 编译采用双配置：tsconfig.json 覆盖 renderer 与 shared 代码（noEmit，供 Vite 使用），tsconfig.main.json 专为主进程编译输出到 dist/main。Vite 以 src/renderer 为 root 构建至 dist/renderer，主进程入口指向 dist/main/main/main.js。pnpm-workspace.yaml 显式允许 @ffmpeg-installer/darwin-x64 与 protobufjs 的 native 构建。根 scripts 通过 concurrently 并行启动 Vite dev server、tsc watch 与 Electron，形成统一的 dev/build/start 工作流。
