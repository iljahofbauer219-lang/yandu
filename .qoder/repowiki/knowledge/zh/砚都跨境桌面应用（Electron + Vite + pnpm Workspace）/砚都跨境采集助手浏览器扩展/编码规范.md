- 所有跨进程通信统一通过 `chrome.runtime.sendMessage` 发送带 `type` 字段的消息对象，service worker 内按 `message.type` 分发处理逻辑。
- API 调用封装为统一的 `api(path, options)` 函数，自动附加 Bearer Token 并将非 2xx 响应转换为带错误信息的 Error。
- DOM 注入的按钮使用固定类名前缀 `sourcing-collector-button` 配合修饰类（如 `sourcing-collector-floating`、`sourcing-collector-inline`）区分位置样式。
- 产品数据提取通过正则表达式从页面文本中提取价格、库存、运费、折扣等字段，失败时回退为空字符串或 null。
- UI 反馈通过统一的 `show(text, kind)` 函数设置消息文本和 CSS 类名（空字符串、'ok'、'error'）来呈现状态。
