- 配置与评分结果统一使用 `@dataclass(frozen=True)` 定义不可变数据结构（Profile、Score），并通过 `asdict()` 序列化到 JSON 报告。
- 可选依赖（exif、masking）采用 `try: from .xxx import ... except (ImportError, ModuleNotFoundError): def fallback(...)` 模式提供空实现回退，保证基础功能可用。
- CLI 入口统一使用 `argparse` 解析参数，`main()` 返回整数退出码并通过 `raise SystemExit(main())` 抛出，异常统一捕获并以 `{"error": ...}` JSON 写入 stderr。
- 路径处理一律通过 `pathlib.Path.resolve()` 获取绝对路径，输出目录通过 `parent.mkdir(parents=True, exist_ok=True)` 自动创建。
- 随机性由 `random.Random(seed)` 显式实例化而非全局 `random`，确保所有变换步骤可复现。
