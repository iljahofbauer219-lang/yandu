- 每个服务暴露为导出类，构造函数接收 `apiKey` 和 `baseUrl` 作为依赖注入参数，便于测试与配置切换。
- 对外部 HTTP 请求统一使用 `Authorization: Bearer ${apiKey}` 头部，失败时抛出包含 HTTP 状态码和原始错误信息的 `Error`。
- 对可能超时的外部调用采用显式超时控制（如 `AbortSignal.timeout(15_000)`）或手动轮询循环（如 `pollTask` 最多 60 次 × 2 秒）。
- 输入参数在进入 API 前进行清洗与边界限制（如关键词截断至 120 字符、数量取 1~最大值范围、URL 白名单校验）。
- 批量操作采用分片批处理（翻译 BATCH_SIZE=8）配合串行请求队列，避免并发超限。
