本模块由四个独立的 Service 类组成，均位于 `src/main/services/` 下，各自面向一个外部 AI 能力：
- `BailianImageService`：对接阿里云百炼多模态生图 API，按模型族（qwen-image、wan2.7、z-image-turbo）选择同步或异步端点，并内置轮询器 `pollTask` 等待任务完成。
- `BailianTranslationService`：基于 qwen-mt-flash 的批量翻译，通过内部请求队列与指数退避重试实现限流保护，并提供内存级去重缓存。
- `DeepSeekCommandService`：将自然语言解析为结构化 `IntelligentCommand`，使用 `response_format: json_object` 强制 JSON 输出并在本地 `validate` 中做二次校验。
- `RealShiftService`：通过 `child_process.spawn` 启动 Python 脚本 `tools/realshift/worker.py` 执行本地图片处理，结果以 data URL 返回。

依赖方向单一：所有服务仅从 `../../shared/contracts` 导入共享类型，不反向依赖业务层；网络请求统一使用 Node.js 原生 `fetch`，错误通过抛出带语义化消息的 `Error` 向上冒泡。
