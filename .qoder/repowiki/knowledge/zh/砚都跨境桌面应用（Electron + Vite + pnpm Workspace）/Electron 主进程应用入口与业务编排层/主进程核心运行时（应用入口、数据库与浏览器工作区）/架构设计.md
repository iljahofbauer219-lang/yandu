模块由三个文件构成主进程的三层职责：
- `src/main/main.ts` 是 Electron 应用入口，集中创建各 Service 实例（BailianImageService、EbayService、ArkVideoService 等），定义并暴露所有业务函数（如 `openEbaySellerHub`、`downloadEbayLocalProduct`、`runEbayAcceptance`、`syncCpscRecalls` 等），通过 `ipcMain` 与渲染进程通信；同时维护全局单例 `mainWindow`、`workspace`、`database`、`feishuBot` 以及任务 Map。
- `src/main/database/AppDatabase.ts` 基于 Node 内置 `node:sqlite` 的 `DatabaseSync` 在用户目录 `sourcing-data.sqlite` 中建立 WAL 模式数据库，构造函数内执行大量 `CREATE TABLE IF NOT EXISTS` 语句完成 schema 自举，并提供对 selection、supply、ebay、compliance 等域的全部 CRUD 方法。
- `src/main/browser/BrowserWorkspace.ts` 封装 Electron `WebContentsView` 生命周期，按平台（ozon/1688/GIGACLOUD/eBay）隔离 partition、UA、代理策略，支持多标签页、插件注入（`__crossBorderCollector`、`__crossBorderEbayPlugin`）、自动采集保护（防风控/验证码/频率限制）以及与 Seller Hub 的交互（读取商品详情、预填修订页、视频上传等）。
依赖方向单向：`main.ts` → `BrowserWorkspace` + `AppDatabase` + 各 `services/*`，`BrowserWorkspace` 不反向依赖 main，仅通过 `executeJavaScript` 与页面脚本通信。
