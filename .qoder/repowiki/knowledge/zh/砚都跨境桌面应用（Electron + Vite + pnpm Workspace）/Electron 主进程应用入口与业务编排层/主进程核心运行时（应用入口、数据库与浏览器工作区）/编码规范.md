- 对外暴露的业务函数统一以 `if(!database) throw new Error('数据库尚未初始化')` / `if(!workspace) throw new Error('应用内浏览器尚未初始化')` 开头做前置守卫，再执行业务逻辑。
- eBay 相关操作通过 `workspace.openCredentialLogin` 或 `newEbayTab` 打开受控标签，URL 白名单校验使用 `allowed(url)` 闭包，仅允许 `https:` 且域名匹配 `ebay.com` 及其子域。
- 数据库表定义集中在 `AppDatabase` 构造函数的 `this.database.exec(...)` 大段 SQL 中，使用 `CREATE TABLE IF NOT EXISTS` + `INSERT OR IGNORE` 实现幂等自举，索引统一以 `idx_表名_字段` 命名。
- 浏览器插件注入采用 `view.webContents.executeJavaScript(String.raw\`...\`)` 将完整 IIFE 注入页面，通过 `window.__crossBorderCollector` / `window.__crossBorderEbayPlugin` 暴露 `snapshot/sync/remove/stop` 四件套 API。
- 所有外部 HTTP 请求统一使用 `fetch` + `AbortSignal.timeout(ms)` 设置超时，错误分支统一捕获 `error instanceof Error ? error.message : String(error)` 并返回结构化结果。
- 图片处理通过 `ebayImageFormat(mimeType)` 映射支持的 MIME 到 `{format,extension}`，尺寸解析针对 png/gif/bmp/tiff/webp/heic/avif/jpeg 分别手写头部解析，失败时回退 `{width:0,height:0}`。
