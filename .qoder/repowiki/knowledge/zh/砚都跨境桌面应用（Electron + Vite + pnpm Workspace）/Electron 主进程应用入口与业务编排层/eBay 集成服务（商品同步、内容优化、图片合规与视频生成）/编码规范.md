- 所有 LLM 调用统一使用 `fetch` 发送 JSON POST 到 `/chat/completions`，携带 `Authorization: Bearer <apiKey>`、`response_format: {type:'json_object'}` 与 `AbortSignal.timeout` 超时控制。
- LLM 返回的文本先经 `extractJson`（基于大括号深度计数）提取首个完整 JSON 对象，再按契约类型做安全字段映射与截断保护。
- 外部依赖缺失或未配置时不抛错，而是返回保守的 fallback 结果（如 REVIEW 状态、空数组、默认提示），确保服务可降级运行。
- 错误信息使用中文描述，包含 HTTP 状态码、模型名称或具体失败原因，便于调试与用户反馈。
- 服务类构造参数均为 readonly 私有字段（clientId/clientSecret/ruName、apiKey/baseUrl/model、rootDirectory），通过方法暴露功能而非暴露内部状态。
