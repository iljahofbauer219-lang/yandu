单一 React 函数组件 `EbayLocalListingEditor` 作为模块入口，通过 props 接收只读的 `product` 和可编辑的 `draft`（类型为 `EbayLocalProductUpdateInput`），并通过 `onChange` 回调以不可变方式更新 draft；所有副作用（保存、上传、准备 Seller Hub）由父组件通过 `onSave`/`onUpload`/`onPrepare` 处理，组件本身无状态提升。
- 校验逻辑内聚在模块级函数 `validateDraft`，返回带 `level`（ERROR/WARNING）、`section`、`message` 的结构化问题列表，由 `useMemo` 缓存计算。
- 媒体管理通过 `moveMedia`、`makeMain`、`removeMedia` 三个纯函数操作 `draft.media` 数组并同步维护 `sortOrder`。
- 样式拆分为三个独立 CSS 文件：`ebay-local-listing-editor.css`（主布局，被 import 但不在本目录快照中）、`ebay-local-listing-pricing.css`（定价表单网格布局）、`ebay-local-listing-validation.css`（校验面板与响应式适配），组件通过 className 前缀 `ebay-revise-*` 保持命名空间隔离。
- 依赖方向单向：组件 → shared contracts 类型定义 → 外部 CSS，不反向依赖其他 renderer 模块。
