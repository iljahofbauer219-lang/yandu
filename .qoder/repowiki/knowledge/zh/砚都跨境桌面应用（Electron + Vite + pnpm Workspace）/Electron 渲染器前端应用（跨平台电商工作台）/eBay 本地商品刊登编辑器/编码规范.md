- 组件通过 props 暴露受控状态（`draft` + `onChange`），内部不直接修改外部数据，而是返回新对象 `{...draft, [key]: value}` 触发父组件更新。
- 校验结果统一使用结构化对象 `{level: 'ERROR'|'WARNING', section: string, message: string}` 表示，并通过 `useMemo` 基于 `draft` 缓存计算。
- CSS 类名统一采用 `ebay-revise-*` 前缀命名空间，按功能拆分到独立 `.css` 文件并由组件集中 import。
- 媒体项操作（移动、设为主图、删除）均以不可变方式生成新数组并同步维护 `sortOrder` 字段。
- 用户输入通过 `inputMode`、`maxLength`、`accept` 等 HTML 属性配合前端正则/数值校验双重约束（如币种三位大写、标题 80 字符限制）。
