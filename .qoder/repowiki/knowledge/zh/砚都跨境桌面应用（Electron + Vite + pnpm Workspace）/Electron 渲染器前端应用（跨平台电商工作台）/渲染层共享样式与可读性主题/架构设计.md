本模块由一组平铺在 `src/renderer/` 下的独立 CSS 文件组成，按职责划分：
- `styles.css`：应用基础布局（`.app-shell`、`.sidebar`、`nav`、`main`、`.workspace`）与默认绿色主题；随后通过二次 `:root` 变量覆盖切换为 Apple-style Tiffany 主题，并包含大量组件级样式（产品卡片、浏览器面板、支持页面、仓库仪表盘、eBay 内容中心等）。
- `ui-readability.css`：声明式可读性层，仅通过 CSS 变量（`--ui-text-*`、`--ui-control-height`、`--ui-radius` 等）和 `:where()` 选择器对已有模块的字体大小、行高、控件高度做视觉覆盖，不引入业务逻辑。
- `image-studio.css`：图像工作室工作区（左侧工具面板 + 右侧画布 + 设置侧栏）、库存目录、发布工作台、eBay 多店铺工作区、图片生成/对比/自然化流水线等。
- `ebay-acceptance-readable.css`：eBay 发布验收中心的可读性排版。
- `compliance*.css`：合规子系统样式，按阶段拆分——`compliance.css`（基线）、`compliance-gate.css`（门禁状态条/维度按钮/视觉合规）、`compliance-phase3.css`（召回操作）、`compliance-stage8.css`（执行面板）、`compliance-v2.css`（v2 工作区/监控/审计/许可审批）、`compliance-v2-review.css`（文档审阅）。
依赖方向单向向下：各模块 CSS 仅通过类名作用于对应 HTML 结构，无跨文件 @import，主题切换通过覆盖 `:root` 变量实现。
