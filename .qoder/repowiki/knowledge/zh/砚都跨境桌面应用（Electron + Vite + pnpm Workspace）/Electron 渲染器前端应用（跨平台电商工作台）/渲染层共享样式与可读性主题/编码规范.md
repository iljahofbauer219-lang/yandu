- 使用 `:root` CSS 自定义属性集中管理主题色（如 `--tiffany`、`--tiffany-soft`、`--ink`、`--muted`、`--line`、`--panel`、`--canvas`），并通过覆盖同一变量实现主题切换。
- 组件类名采用 `.xxx-panel` / `.xxx-workspace` / `.xxx-heading` / `.xxx-grid` 等命名模式，标题统一用 `<b>` 和 `<small>` 子元素承载主副文本。
- 状态语义通过修饰类表达，如 `.active`、`.selected`、`.passed`、`.blocked`、`.review_required`、`.pending`、`.error`、`.success`，配合边框色或背景色区分。
- 响应式通过 `@media (max-width: ...)` 断点调整 Grid 列数和布局密度，优先保证可读性再压缩列数。
- 可读性层 `ui-readability.css` 使用 `:where()` 选择器和统一的 CSS 变量（`--ui-text-*`、`--ui-control-height`、`--ui-radius`）覆盖字体大小、行高、控件高度，避免侵入业务样式。
