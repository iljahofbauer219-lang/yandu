- 所有业务页面以独立 TSX 组件形式存在，由 App.tsx 通过条件渲染或路由状态切换显示
- 与 Electron 主进程的通信统一通过 window.desktop.* 命名空间的异步方法，错误处理采用 readableError 包装
- 用户配置与临时数据统一通过 localStorage 的特定 key 前缀（如 ebay-profit-assumptions:、collection-protection:、ebay-image-source-curation:v1:）进行序列化存储
- 类型定义全部从 ../shared/contracts 导入，组件内部不重复声明跨模块共享的类型
- CSS 按功能域拆分为独立文件（compliance*.css、ebay-*.css、image-studio.css、ui-readability.css），由 main.tsx 统一引入
