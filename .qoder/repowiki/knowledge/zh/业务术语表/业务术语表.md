### 产品目录
- 定义：砚都跨境应用中用于展示和管理商品的侧边栏组件，包含线上产品、本地产品、优品仓库三个页签，支持分类筛选、搜索过滤等功能。在 UI 可读性优化中，统一调整了标题、分类名、徽标等元素的字号大小，确保 WCAG AA 对比度标准。
- 别名：产品目录侧边栏、catalog sidebar

### 大健云仓
- 定义：砚都跨境应用的采集来源平台之一，通过 Chrome 浏览器扩展程序实现商品数据采集。用户在平台上使用筛选条件后，可通过插件标记并采集到砚都跨境系统中。
- 别名：gigab2b、GigaB2B

### 采集任务
- 定义：砚都跨境应用中的核心业务流程单元，包括关键词采集、商品筛选、比价分析、选品决策等环节。每个任务有独立的状态机管理，支持暂停、恢复、取消等操作。
- 别名：selection task、collection task

### Ozon 会话
- 定义：Electron 应用中为俄罗斯电商平台 Ozon 维护的独立浏览器会话，强制使用 direct 模式绕过代理，使用标准 Chromium User-Agent 和俄语请求语言，支持商品详情采集和列表浏览。
- 别名：ozon session、俄罗斯平台会话

### 1688 会话
- 定义：Electron 应用中为阿里巴巴批发网 1688.com 维护的独立浏览器会话，用于国内货源采集和比价分析，与 Ozon 会话共享相同的持久化机制。
- 别名：1688 session、阿里巴巴会话

### SQLite 状态机
- 定义：砚都跨境应用中使用 SQLite 数据库实现的业务状态管理系统，存储任务状态、商品信息、工作流事件等数据，支持应用重启后的状态恢复和数据一致性保证。
- 别名：sourcing-data.sqlite、状态机数据库

### 工作流事件
- 定义：记录跨阶段操作轨迹的事件日志系统，保存在 `workflow_events` 表中，用于追踪采集、比价、选品、入库、上架等完整业务流程的操作历史。
- 别名：workflow events、操作轨迹

### 真机验收
- 定义：砚都跨境项目中的质量保证流程，指在真实的 Electron 环境中进行的功能测试和界面验证，确保应用在真实用户环境下正常工作。
- 别名：real device testing、Electron 真机测试

### WCAG AA 对比度
- 定义：Web 内容无障碍指南的 AA 级对比度标准，要求次要文字前景色与背景色的对比度至少达到 4.5:1，砚都跨境应用的产品目录 UI 优化中严格遵循此标准。
- 别名：对比度标准、无障碍对比度

### 配对码
- 定义：砚都跨境桌面应用与 Chrome 浏览器扩展之间的安全配对标识，6 位数字代码，用于建立桌面应用与浏览器扩展之间的安全通信连接。
- 别名：pairing code、配对标识
