# 正式报告质量门误判修复验收

验收日期：2026-08-11

## 故障根因

1. 竞店表格中商品售价与后续单元格的“认证”描述被跨列拼接，误判成未经核验的合规成本。
2. “月销量增速<10%持续2月”等未来复盘阈值被误判成系统已抓取的历史销量趋势。
3. “首月销量>100”等短期测试目标被误判成系统已抓取的历史销量。
4. 无结尾竖线的 Markdown 表格行没有进入确定性降级；降级结果只有在问题数减少时才被采用，可能保留原始失败内容。

## 修复结果

- 合规判断改为单元格范围判断；商品售价不再与其他单元格的认证描述串联。
- 风险预警、补货/停止条件、测试目标和短中长期计划中的未来阈值不再当作历史市场证据。
- Markdown 表格解析同时支持有、无结尾竖线。
- 最终确定性降级结果始终重新校验并采用，最多执行两轮直至稳定。
