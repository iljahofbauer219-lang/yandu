### 3.2 利润模拟（模型）

```
假设示例（仅作参考，非实际数据）：
- 售价：$29.99

- 仓储：$0.30/件/月（周转45天）

- 退货损耗（4%）：$1.20
- 汇损（1.5%）：$0.45

总成本：$3.5 + $1.2 + $5.47 + $4.50 + $0.30 + $6.60 + $1.20 + $0.45 = $23.22
毛利：$29.99 - $23.22 = $6.77（22.6%）
净利（扣除其他运营费用后）：约$4.50（15%）

⚠️ 以上为模型示例，所有数字需根据实际产品数据重新计算
```

## 四、合规与供应链评估（满分 30 分）

### 4.1 美国站合规要求清单

| 合规项 | 要求 | 严重性 | 当前状态 |
|--------|------|--------|----------|
| **FDA注册** | 宠物食品/零食/营养品需FDA注册；非食品类器具（碗、饮水机）需符合FDA食品接触材料标准 | 🔴 高 | ⚠️ 需确认产品是否涉及 |
| **CPC证书** | 如产品被视为"儿童产品"（注意：部分宠物玩具被CPSC归类可能有争议） | 🟡 中 | ⚠️ 需确认 |
| **加州Prop 65** | 含特定化学物质需警告标签；塑料/橡胶宠物用品重点关注邻苯二甲酸酯、BPA、铅 | 🔴 高 | ⚠️ 需材质检测报告 |
| **FCC** | 含蓝牙/WiFi的智能宠物设备需FCC认证 | 🔴 高 | ⚠️ 如涉及智能喂食器/饮水机 |
| **UL/ETL** | 带电宠物用品（加热垫、烘干箱、智能设备）需安全认证 | 🔴 高 | ⚠️ 如涉及带电产品 |
| **USDA APHIS** | 含动物源材料的宠物玩具（如牛皮骨、鹿角）需USDA审批 | 🔴 高 | ⚠️ 如涉及动物材料 |
| **ASTM F963** | 宠物玩具参考标准（虽非强制，但建议） | 🟡 中 | ⚠️ 建议检测 |
| **商标/品牌注册** | Amazon Brand Registry 2.0 | 🟡 中 | ⚠️ 需确认 |
| **产品责任险** | 美国平台通常要求$100万以上责任险 | 🔴 高 | ⚠️ 需购买 |

### 4.2 欧盟站合规清单（如扩展欧洲）
