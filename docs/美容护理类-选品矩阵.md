```
推荐主推SKU：宠物去浮毛梳（Deshedding Brush）——差异化齿形设计避开FURminator专利
推荐补充SKU：宠物指甲剪（Nail Clipper）——刚需、低风险、高复购

理由：两个都是纯固态（不锈钢+ABS/TPU），合规只需Prop65材质检测，
      无FDA/FCC/EPA/液体/气雾罐任何红线，物流小件友好，可共享同一条供应链。
```

## 三、主推SKU深析——去浮毛梳（Deshedding Brush）

### 3.1 为什么是它
1. **客单价高**：$15-28，是美容护理类里除带电产品外最高的，能支撑利润
2. **刚需+痛点明确**：猫狗换毛季掉毛是高频痛点，"减少掉毛90%"是强卖点
3. **固态小件**：物流友好，FBA配送费低
4. **品牌溢价空间**：FURminator卖$25-40，中端$15-20有明确空白带

### 3.2 合规（几乎零门槛）
| 合规项 | 结论 |
|--------|------|
| FDA | 🟢 不涉及（非食品接触） |
| FCC/UL | 🟢 不涉及（非带电） |
| EPA/FIFRA | 🟢 不涉及（无驱避/药物声称） |
| 动物源材料 | 🟢 不涉及（不锈钢+ABS） |
| Prop 65 | 🟡 需测不锈钢/ABS的铅、邻苯二甲酸酯（$500-800） |
| 窒息警告标签 | 🟡 塑料袋包装需加标签 |
| 专利 | 🟡 **唯一需注意：FURminator齿形专利（US 7,331,311等）** |

### 3.3 专利规避——这是能否做的关键
FURminator的核心专利是**"特定齿形+齿间距的脱毛刀头"**。规避方案：
1. 改用**圆头不锈钢细齿+弧形齿排**（不复制其专利的"梯形脱毛刃"结构）
2. 或采用**双面设计（一面针梳+一面橡胶去浮毛）**，避开单一脱毛刃
3. 或聚焦**猫用小型化**，FURminator主要专利集中在犬用大号刀头

> 🔴 **红线门禁**：上架前必须做FTO检索（$1,000-2,000，7-14天），确认齿形设计不落入FURminator专利范围。这是唯一红线，但比自洁梳的"退毛机构专利"更容易规避（退毛机构专利是硬伤，齿形可以重新设计）。

## 四、补充SKU深析——指甲剪（Nail Clipper）

### 4.1 定位
- 刚需、低决策门槛、轻小件，用于**补充产品线、提升店铺健康度**
- 客单价$8-16，利润薄但风险极低，可快速测款验证供应链

### 4.2 合规
- 纯不锈钢+ABS，无任何红线，Prop65一般直接通过（不锈钢不含铅）
- 专利成熟，几乎零侵权风险

### 4.3 策略
- 不作为主推（利润薄），作为**组合销售/变体**存在，或在主推去浮毛梳跑通后作为第二款上架

## 六、关键判断

```
✅ 做去浮毛梳，如果：
   · FTO通过（齿形避开FURminator）
   · 采购成本≤¥12
   · 售价稳在$18.99-21.99
   · 差异化卖点清晰（如"猫用mini号""双面设计"）

❌ 不做，如果：
   · FTO发现齿形无法规避FURminator
   · 竞品大量涌入压到$12.99
   · 供应商样品质量不过关（齿易弯/掉毛梳不下来）

🎯 相比之前评估的"自洁梳"：
   去浮毛梳 = 同是美容护理类，但专利风险从"退毛机构硬伤"降级为"齿形可重设计"，
   合规同样干净，客单价更高、净利更好（24.4% vs 14.7%）。
```
