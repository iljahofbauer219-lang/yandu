# UI 第三阶段验收记录

验收日期：2026-08-03  
试点范围：eBay AI 优化中的阶段式图片生成面板。  
结论：试点范围通过；未扩散至其他业务模块。

## 1. 实现结果

- 新增兼容 Token：品牌、表面、文字、状态、间距、圆角、焦点与深色映射。
- 新增基础组件样式及 `Button`、`StatusBadge`、`Notice`、`Card` 原语。
- 图片优化试点增加“当前任务”和明确的完成条件。
- 并发参数移入默认收起的高级设置。
- 重复分析/重新生成降为次按钮；确认进入下一阶段保持唯一主操作。
- 步骤导航增加当前、完成、锁定的可访问名称。
- 错误使用 `role="alert"`，异步进度使用 `aria-live="polite"`。
- 禁用按钮提供进入条件；交互控件补齐 `focus-visible`。
- 试点业务文字清除小于 12px 的声明，并支持减少动态效果。

## 2. 真实浏览器检查

验收页直接加载生产 `EbayImageStagePanel` 源码、Token、组件样式、业务样式和深色主题；模拟数据只替代后端商品与图片，不替代组件实现。

| 检查项 | 结果 | 证据摘要 |
|---|---|---|
| 1180×720 浅色 | 通过 | `scrollWidth = clientWidth = 1180`，当前任务单列降级，无横向溢出 |
| 1180×720 深色 | 通过 | 面板、区块标题和正文深色映射正确，无浅底浅字 |
| 1440×900 浅色 | 通过 | 当前任务双栏，完成条件同层展示，高级设置默认收起 |
| 1440×900 深色 | 通过 | `scrollWidth = clientWidth = 1440`，表面与文字颜色映射正确 |
| 状态交互 | 通过 | 选择 1 张原图后，当前任务从“选择原图”切换为“生成并核对事实卡” |
| 步骤语义 | 通过 | 恰有 1 个 `aria-current="step"`，锁定步骤为 disabled 且名称说明原因 |
| 异步播报 | 通过 | 恰有 1 个 polite live region；错误区域为 alert |
| 键盘焦点 | 通过 | 原图选择按钮显示 2px 品牌色 outline 与焦点环 |
| 业务字号 | 通过 | 试点计算字号集合为 12、13、14、16、18px |
| 减少动态效果 | 通过 | 源码包含 `prefers-reduced-motion` 覆盖 |

真实检查首次发现深色主题的旧局部变量未映射，出现浅底浅字；已将 `--bg-*`、`--text-*`、`--border`、`--accent` 映射至新 Token，复验通过。
