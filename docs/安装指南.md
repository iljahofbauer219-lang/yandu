# 砚都跨境 桌面端 · 安装指南

适用对象：全体运营同事
下载地址：**http://114.55.149.192/download/**（浏览器打开即可看到下载按钮）

当前版本：v1.0.14

---

## 一、下载安装包

打开上面的下载页，按自己的电脑系统选择：

| 系统 | 下载文件 | 说明 |
|------|----------|------|
| Windows（绝大多数同事） | YanduCrossBorder-Setup-1.0.14.exe | 约 131 MB |
| macOS（Intel 芯片） | YanduCrossBorder-1.0.14-x64.dmg | 约 146 MB |

> 不确定自己的 Mac 是什么芯片？点左上角苹果菜单 →「关于本机」，若「芯片/处理器」写的是 Intel，用 macOS 版即可。

## 二、Windows 安装步骤

1. 双击下载好的 `YanduCrossBorder-Setup-1.0.14.exe`。
2. 若弹出「Windows 已保护你的电脑」（SmartScreen 提示，因为软件未购买微软签名，属正常现象）：
   - 点击 **更多信息** → **仍要运行**。
3. 按安装向导下一步，可自选安装目录，等待安装完成。
4. 桌面会出现「砚都跨境」快捷方式，双击启动。

## 三、macOS 安装步骤

1. 双击下载好的 `YanduCrossBorder-1.0.14-x64.dmg`。
2. 把「砚都跨境」图标拖到 Applications 文件夹。
3. 首次打开（软件未做苹果签名，属正常现象）：
   - 在启动台/应用程序里 **右键点击「砚都跨境」→ 选择「打开」** → 弹窗中再点「打开」。
   - 若提示「文件已损坏，无法打开」，在终端执行一次：
     `xattr -cr /Applications/砚都跨境.app` 后重新打开。
4. 之后正常双击打开即可。

## 四、登录与账号

- 打开应用后进入登录页，使用 **管理员分配的手机号账号 + 密码** 登录。
- 应用默认已连接中央服务器（114.55.149.192），无需任何配置。
- 登录页底部有「服务器」折叠区，正常情况下 **不要修改**。

## 五、自动更新

- 应用启动后会自动检查新版本；发现新版本会后台下载，下载完成弹窗提示「立即重启安装」。
- 也可以直接重新下载安装包覆盖安装（数据不受影响）。

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 提示「该手机号已注册」 | 说明账号已存在，改用登录而不是注册；忘记密码找管理员重置 |
| 登录一直转圈/失败 | 检查网络能否访问公司服务器；联系管理员确认服务状态 |
| Windows 杀毒软件误报 | 选择「允许/保留文件」，软件无恶意行为 |
| 桌面快捷方式打不开 | 右键 → 以管理员身份运行 试一次 |
