## 一、保留不译（原样保留）

- 品牌名、型号、SKU（用户事实卡提供）
- 平台专有名：FBA、Prime、Buy Box、A+、Cassini 不出现于前台文案（仅内部规则引用）
- 认证标识名：CE、FCC、RoHS、CPC（作为标识名保留，但「获得认证」的声称必须与事实卡一致）

## 四、禁译/合规改写表

| 中文源词 | 风险 | 改写规则 |
|---------|------|---------|
| 医用级 | 疗效暗示 | 禁直译 medical grade；无认证时改写为具体用途描述（如 "suitable for sensitive skin" 需有依据） |
| 抗菌/抑菌 | 需认证证据 | 无证据时改写为 "easy to clean / quick-drying" 等功能描述 |
| 无毒 | 需认证（如 CPSIA） | 有证据时写 "BPA-free"（仅当事实卡含 BPA-free）；无证据删除 |
| 环保 | FTC Green Guides | 无证据时改写为具体可验证描述（如 "recyclable packaging"，需事实卡支持） |
| 治疗/治愈 | 疗效红线 | 任何语言一律删除 |
| 美白/祛斑 | 化妆品功效 | 按目标市场化妆品法规，无认证删除或弱化为 "brightening-looking" 类外观描述（需法务确认时标 ⚠️ 人工复核） |
| 最好/第一/100% | 最高级 | en 改 "premium/upgrade"；ja 删除或改具体工艺描述；de 改客观参数 |
| 防水 | 需等级 | 有 IPX 等级按事实卡写 "IPX7 waterproof"；无等级写 "water-resistant" |

## 五、命中自检
