# Listing精造师知识库 · 平台规则库

> 本文档为各平台 Listing 字段规则权威值（默认值，平台政策更新时修订本文档并重新解析）。智能体检索时以本文档为准。

## 一、Amazon

### 站点与语言
US(en-US)、CA(en/fr)、MX(es-MX)、UK(en-GB)、DE(de)、FR(fr)、ES(es)、IT(it)、JP(ja)

### 字段规则
| 字段 | 规则 |
|------|------|
| 标题 | ≤200 字符（部分类目 50-100）；主关键词前 80 字符内；禁促销词、禁 HTML、禁全大写（缩写除外）、禁特殊符号堆砌 |
| 要点 bullet | 5 条；单条 ≤500 字符（建议 200-250）；禁 HTML 与外链；每条以 benefit 或动词开头 |
| 描述 | ≤2000 字符；有 A+ 页面时描述权重降低但仍需完整 |
| 后台搜索词 | ≤249 字节（UTF-8）；不重复标题已有词、不含品牌词/ASIN/主观词 |
| 物品特定属性 | 填充率影响搜索权重，材质/尺寸/颜色必填 |

### 禁词与高风险表述
- 促销类：best seller、top rated、free shipping、on sale、hot item
- 担保类：guarantee（无条件）、money back（需与售后政策一致）
- 疗效类：cure、treat、prevent（疾病语境）、FDA approved（无认证时）
- 环保类：eco-friendly、biodegradable（需证据，FTC Green Guides）
- 日语站：「最高」「No.1」「100%」等最高级（景品表示法）
- 德语站：无依据的功效声称（Heilmittelwerbegesetz 约束思维）

## 二、eBay

### 站点与语言
US/UK/AU(en)、DE(de)、FR(fr)、ES(es)、IT(it)

### 字段规则
| 字段 | 规则 |
|------|------|
| 标题 | ≤80 字符；禁 "wow" "L@@K" 等堆砌词；品牌+型号+核心属性优先 |
| 物品特定属性 | 填充率直接影响 Cassini 搜索权重，能填尽填 |
| 描述 | 允许受限 HTML（禁 script/外链/主动 JS）；移动端优先简洁排版 |
| 副标题 | 付费可选，承载第二关键词组合 |

## 三、Shopee

### 站点与语言
SG(en)、MY(ms/en)、TH(th)、VN(vi)、PH(en/fil)、ID(id)

### 字段规则
| 字段 | 规则 |
|------|------|
| 标题 | ≤120 字符；前 50 字符承载主关键词；授权品牌词置首 |
| 描述 | 允许表情符号与话题标签；分段短句式；关键词重复容忍度高但禁恶意堆砌 |
| 属性 | 类目属性必填项影响筛选曝光 |

### 语气
促销口语化、紧迫感（限时/包邮话术需与店铺活动一致）。

## 四、TikTok Shop

### 站点与语言
US/UK(en)、TH(th)、VN(vi)、MY(ms)、PH(en)

### 字段规则
| 字段 | 规则 |
|------|------|
| 标题 | 短标题（建议 ≤90 字符，按站点实时规则）；口语化、场景词优先 |
| 描述 | 短描述 + 3-5 个 hashtag；社交轻松语气 |
| 禁词 | 医疗疗效、绝对化承诺、站外引流话术 |

## 五、Temu

### 站点与语言

### 字段规则
| 字段 | 规则 |
|------|------|
| 标题 | 关键词密集组合；属性词前置 |
| 描述 | 简洁要点式；性价比直白表达 |

## 六、AliExpress

### 站点与语言
EN、ES、FR、PT、RU 等（平台自动多语展示，卖家维护 EN 主版）

### 字段规则
| 字段 | 规则 |
|------|------|
| 标题 | ≤128 字符；关键词组合式（核心词+属性词+场景词） |
| 描述 | 简单图文结构；功能罗列式 |
| 搜索词 | 堆砌容忍度高于 Amazon，但仍禁无关词 |

## 七、规则使用约定

1. 字符数为「字符」，Amazon 搜索词为「字节」（UTF-8，德语变音/日语假名按多字节计）。
2. 自检表必须逐字段给出「实际字符数/上限」。
3. 平台政策冲突时：红线（禁词/IP/事实）> 平台规则库 > 方法论文档默认值。
