## 一、关键词策略规则

### 1. 主关键词选择
- 优先级：与商品功能 100% 相关 × 搜索量量级 ≥ 1万/月 × 竞争可进入（首页平均评论 < 500）
- 位置：标题前 80 字符内完整出现，不拆词、不改写

### 2. 长尾关键词构成（3-5 个）
- 功能词 + 主词：如 self cleaning + slicker brush
- 场景词 + 主词：如 for home grooming / for travel
- 受众词 + 主词：如 for long hair dogs / for cats and dogs
- 属性词 + 主词：如 stainless steel + brush

### 3. 埋点位置分配
| 位置 | 承载内容 |
|------|---------|
| 标题前部 | 主关键词（完整、不拆分） |
| 标题后部 | 1-2 个长尾（属性/受众） |
| 要点 bullet | 2-3 个长尾自然嵌入（句式完整，不堆砌） |
| 后台搜索词（Amazon） | 与标题/要点不重复的补充词，≤249 字节，空格分隔、无逗号、无重复 |
| 描述 | 主词与长尾的自然复现（密度 ≤ 2%） |

### 4. 负向词（禁嵌入）
- 与商品无关的流量词（如卖梳子埋 "dog food"）
- 竞品品牌词、未授权品牌词
- 主观词（best/cheap/top，Amazon 后台搜索词明确禁止）
